# Chat Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Chat tab where you describe a Python function in plain English, check the spec the Research agent drafts, watch the team solve it with evidence-based arbitration, then ask questions or request changes in the same thread.

**Architecture:** `Coordinator.answer()` runs the shared middle of the pipeline (brief → candidates → tests → sandbox → rulings → repair) that `solve()` now also calls. `hivemind/chat.py` holds the chat-only model calls and spec checking. `hivemind/web/chats.py` keeps each chat as an event list saved to `runs/chats/<id>.json`, run one action at a time in a background thread. The server exposes it under `/api/chats`, and a new `static/chat.js` renders the thread by replaying events.

**Tech Stack:** Python 3.11+ standard library, `http.server` with Server-Sent Events, plain HTML/CSS/JS with no build step, pytest with `ScriptedLLM`.

**Spec:** `docs/superpowers/specs/2026-10-15-chat-design.md`

## Global Constraints

- Python 3.11+; standard library only; no new dependencies (Python or JS).
- `solve()` must keep its model calls, their order and seeds, its transcript and its outcome exactly as before.
- The server binds to `127.0.0.1` only. Chat ids are server-generated and pass `config.is_safe_name`; no request reaches files outside `runs/chats/`.
- A team round is a job under the one-job-at-a-time rule (HTTP 409 with the running job). Drafting, classifying and answering are not.
- Chat files are written as UTF-8 JSON via a temp file and `os.replace`; `runs/chats/` is git-ignored like `runs/demos/`.
- User-facing text is plain English and phrased as what to do (match the existing UI copy).
- Run tests with `.venv/bin/python -m pytest` from the repo root (`~/Documents/AI`). The existing 82 tests must keep passing.

## Review Focus

1. A second message sent while the team is still working (double Enter, two tabs) must be refused with "still working" (409) and must not record a second message: pinned in Task 4 and Task 5.
2. The server restarting mid-action must leave the chat readable, marked interrupted, and retryable: pinned in Task 4 (`load`) and Task 5 (restart + `/retry`).
3. Non-ASCII text (accents, dashes, emoji) in messages and specs must save and reload intact, and the title must cut at 60 characters with "…": pinned in Task 4.
4. A chat whose config was deleted or renamed must say which config is missing (404), not crash: pinned in Task 5.
5. Pressing Go while an experiment or live run is going must say the round has to wait (409 naming the job), while drafting still works: pinned in Task 5.

    def solve(self, task: CodeTask, review: bool = False, on_event=None,
              cancel=None) -> tuple[TaskOutcome, Transcript]:
        """Solve one task. `on_event` receives live progress events (see Transcript.emit);
        setting the `cancel` Event stops the run before its next model call."""
        tr = Transcript(task.task_id, on_event=on_event, cancel=cancel)
        seed = self._seed(task)
        ask = self._asker(tr)

        solo = self._code(ask("coding", self._coder_prompt(task), "solo", seed), task)
        pool = self._pool(task, ask, seed, tr)
        candidates, results, unsafe, cluster = pool.candidates, pool.results, pool.unsafe, pool.cluster
        vote_pick = min(range(self.k), key=lambda i: (unsafe[i], -cluster[i], i))
        stated = [sum(r.passed is True for r in res) for res in results]
        tests_pick = min(range(self.k), key=lambda i: (unsafe[i], -stated[i], -cluster[i], i))
        arb_pick = int(pool.arb_source.rsplit(" ", 1)[1])

        debate_code, debate_source = self._debate(task, candidates, ask, seed)

        grades: dict[str, bool] = {}

        def graded(code: str) -> bool:
            if code not in grades:
                grades[code] = grade(task, code)
            return grades[code]

        candidate_passed = [graded(c) for c in candidates]
        answers = {
            "solo": (solo, "solo coder"),
            "first": (candidates[0], "candidate 0"),
            "vote": (candidates[vote_pick], f"candidate {vote_pick}"),
            "debate": (debate_code, debate_source),
            "tests_only": (candidates[tests_pick], f"candidate {tests_pick}"),
            "arbitration_select": (candidates[arb_pick], f"candidate {arb_pick}"),
            "arbitration": (pool.arb_code, pool.arb_source),
        }
        outcome = TaskOutcome(
            task_id=task.task_id,
            candidates=candidates,
            candidate_passed=candidate_passed,
            answers={name: {"code": code, "source": src, "passed": graded(code)}
                     for name, (code, src) in answers.items()},
            diagnostics=self._diagnostics(task, pool.cases, pool.sigs, unsafe, pool.rulings,
                                          pool.disputes, pool.scores, pool.failing, pool.repaired),
        )
        if review:
            outcome.review = self.review(task, pool.arb_code, ask, seed)
        return outcome, tr

    def answer(self, task: CodeTask, on_event=None, cancel=None) -> tuple[ChatAnswer, Transcript]:
        """The shared steps alone, for a problem with no hidden tests: no solo baseline, no
        debate, no grading. Used by the Chat tab."""
        tr = Transcript(task.task_id, on_event=on_event, cancel=cancel)
        pool = self._pool(task, self._asker(tr), self._seed(task), tr)
        failures = [{"call": pool.cases[j].call, "expected": self._expected(pool.cases[j], rule),
                     "got": pool.arb_results[j].signature}
                    for j, rule in sorted(pool.verified.items())
                    if not _satisfies(rule, pool.arb_results[j])]
        spec_cases = sum(c.source == "spec" for c in pool.cases)
        ruled = sum(rule is not None for _, _, rule in pool.rulings)
        working = bool(pool.arb_code) and (not pool.arb_results
                                           or any(r.is_answer for r in pool.arb_results))
        answer = ChatAnswer(
            code=pool.arb_code, source=pool.arb_source, candidates=pool.candidates,
            unsafe=pool.unsafe, working=working,
            verified_total=len(pool.verified), verified_passed=len(pool.verified) - len(failures),
            spec_cases=spec_cases, ruled_cases=ruled,
            undisputed_cases=len(pool.verified) - spec_cases - ruled,
            failures=failures, rulings=[asdict(r) for _, r, _ in pool.rulings],
            distinct_behaviours=len(set(pool.sigs)), repaired=pool.repaired)
        return answer, tr

    def _pool(self, task: CodeTask, ask, seed: int, tr: Transcript) -> _Pool:
        """Brief, candidates, team tests, sandbox, arbitration and repair: the steps every
        strategy and the Chat tab share."""
        brief = ask("research", f"Analyse this function specification for the team.\n\n{task.spec}",
                    "brief", seed)
        candidates = [
            self._code(ask("coding", self._coder_prompt(task, brief, APPROACH_HINTS[i % len(APPROACH_HINTS)]),
                           f"candidate:{i}", seed + 1 + i), task)
            for i in range(self.k)
        ]
        tests_text = ask("testing", self._tester_prompt(task), "tests", seed)
        cases = self._cases(task, tests_text)
        case_dicts = [{"call": c.call, "expected": c.expected} for c in cases]
        results = [run_cases(build_program(task, c), case_dicts) for c in candidates]
        unsafe = [bool(static_scan(c)) for c in candidates]

        sigs = [tuple(r.signature for r in res) for res in results]
        tr.emit("evidence", candidates=self.k, cases=len(cases),
                spec_cases=sum(c.source == "spec" for c in cases),
                tester_cases=sum(c.source == "tester" for c in cases),
                distinct_behaviours=len(set(sigs)), unsafe_candidates=sum(unsafe))
        runnable = [not res or any(r.is_answer for r in res) for res in results]
        # Programs that never produce a result cannot form a voting bloc.
        cluster = [sum(s == t and ok for t, ok in zip(sigs, runnable)) if runnable[i] else 0
                   for i, s in enumerate(sigs)]

        verified, rulings, disputes = self._arbitrate(task, cases, results, ask, seed)
        tr.emit("rulings", disputes=disputes, rulings=[asdict(r) for _, r, _ in rulings])

        def score(res: list[CaseResult]) -> int:
            return sum(_satisfies(rule, res[j]) for j, rule in verified.items())

        scores = [score(res) for res in results]
        arb_pick = min(range(self.k), key=lambda i: (unsafe[i], -scores[i], -cluster[i], i))
        arb_code, arb_source, arb_results = candidates[arb_pick], f"candidate {arb_pick}", results[arb_pick]
        failing = [j for j, rule in verified.items() if not _satisfies(rule, results[arb_pick][j])]
        repaired = False
        if self.repair and failing:
            fixed = self._code(ask("coding", self._repair_prompt(task, arb_code, cases, verified,
                                                                  results[arb_pick], failing),
                                   "repair", seed + 50), task)
            if fixed and not static_scan(fixed):
                fixed_results = run_cases(build_program(task, fixed), case_dicts)
                if score(fixed_results) > scores[arb_pick]:
                    arb_code, arb_source, arb_results, repaired = (
                        fixed, f"repair of candidate {arb_pick}", fixed_results, True)
        return _Pool(candidates, cases, results, unsafe, sigs, cluster, verified, rulings, disputes,
                     scores, arb_code, arb_source, arb_results, failing, repaired)
```

- [ ] **Step 3: Create `hivemind/web/events.py`**

```python
"""An append-only list of events with increasing `seq`, kept for replay.

Readers poll `wait_events(after=seq)`, so a page that reconnects (or opens late)
gets the whole history first and then each new event as it happens.
"""

from __future__ import annotations

import threading
import time


class EventLog:
    def __init__(self, events: list[dict] | None = None):
        self._events: list[dict] = list(events or [])
        self._cond = threading.Condition()
        self._closed = False

    def emit(self, event: dict) -> dict:
        with self._cond:
            stamped = {"seq": len(self._events) + 1, "time": time.time(), **event}
            self._events.append(stamped)
            self._cond.notify_all()
            return stamped

    def close(self) -> None:
        """No more events will come, so waiting readers return at once."""
        with self._cond:
            self._closed = True
            self._cond.notify_all()

    @property
    def last_seq(self) -> int:
        with self._cond:
            return self._events[-1]["seq"] if self._events else 0

    def events_after(self, after: int) -> list[dict]:
        with self._cond:
            return list(self._events[max(0, after):])

    def wait_events(self, after: int, timeout: float) -> list[dict]:
        """Events with seq > `after`, waiting up to `timeout` seconds for the next one."""
        with self._cond:
            if len(self._events) <= after and not self._closed:
                self._cond.wait(timeout)
            return list(self._events[max(0, after):])
```

```python
"""Chat with the team: turn a plain-English request into a spec, and talk about the answer.

The team itself solves a chat problem with `Coordinator.answer`. This module holds
the three calls only chat needs (draft a spec, read a follow-up as a question or a
change, answer a question) and the check that a spec is something the pipeline can
run: imports, then one function signature whose body is only its docstring.
"""

from __future__ import annotations

import ast
import re
from dataclasses import dataclass

from .agents import Team, Transcript
from .domains.code import CodeTask, doc_example_cases

_FENCE = re.compile(r"```(?:python|py)?\s*\n(.*?)```", re.DOTALL)
_READING = re.compile(r"\b(QUESTION|CHANGE)\b")

_SPEC_FORM = (
    "Reply with exactly one ```python block containing, in this order:\n"
    "- any imports the signature needs (for example: from typing import List)\n"
    "- one function signature with type hints\n"
    "- a docstring, indented by 4 spaces, that states the rules precisely, including edge "
    "cases, and ends with 2 to 4 examples in doctest form:\n"
    "    >>> function_name(arguments)\n"
    "    expected result\n"
    "Do not write the function body: the docstring is the last thing in the block. This is "
    "a specification for the team, not an implementation."
)


class SpecError(ValueError):
    """A spec the pipeline cannot run; the message says what to fix and where."""

    def __init__(self, message: str, line: int | None = None):
        super().__init__(message)
        self.line = line


@dataclass(frozen=True)
class Spec:
    text: str          # imports, signature and docstring, ending with a newline
    entry_point: str
    examples: int      # >>> examples usable as trusted test cases


@dataclass(frozen=True)
class Draft:
    text: str              # what the spec card shows
    spec: Spec | None      # None when the draft is still not a valid spec
    error: str | None


def spec_text(reply: str) -> str:
    """The last ```python block of a reply, or the whole reply when it has none."""
    blocks = _FENCE.findall(reply)
    return (blocks[-1] if blocks else reply).strip("\n")


def _is_stub(node: ast.stmt) -> bool:
    return isinstance(node, ast.Pass) or (isinstance(node, ast.Expr)
                                          and isinstance(node.value, ast.Constant)
                                          and node.value.value is Ellipsis)


def validate_spec(text: str) -> Spec:
    """Check that `text` is imports plus one function whose body is only its docstring.

    A trailing `pass` or `...` is dropped, since the pipeline adds its own stub.
    """
    text = text.expandtabs(4)
    try:
        tree = ast.parse(text)
    except SyntaxError as exc:
        raise SpecError(f"Line {exc.lineno}: {exc.msg}", exc.lineno) from None
    functions: list[ast.FunctionDef] = []
    for node in tree.body:
        if isinstance(node, (ast.Import, ast.ImportFrom)):
            if functions:
                raise SpecError(f"Line {node.lineno}: put imports before the function", node.lineno)
            continue
        if isinstance(node, ast.FunctionDef):
            functions.append(node)
            continue
        raise SpecError(f"Line {node.lineno}: only imports and one function signature belong "
                        f"in the spec", node.lineno)
    if not functions:
        raise SpecError("The spec needs one function: a signature with a docstring")
    if len(functions) > 1:
        line = functions[1].lineno
        raise SpecError(f"Line {line}: the spec can have only one function", line)
    fn = functions[0]
    if fn.decorator_list:
        line = fn.decorator_list[0].lineno
        raise SpecError(f"Line {line}: remove the decorator", line)
    if ast.get_docstring(fn) is None:
        raise SpecError(f"Line {fn.lineno}: add a docstring that says what {fn.name} must do",
                        fn.lineno)
    extra = [n for n in fn.body[1:] if not _is_stub(n)]
    if extra:
        raise SpecError(f"Line {extra[0].lineno}: remove the function body; the team writes it",
                        extra[0].lineno)
    doc = fn.body[0]
    if doc.col_offset != 4:
        raise SpecError(f"Line {doc.lineno}: indent the docstring by 4 spaces", doc.lineno)
    clean = "\n".join(text.splitlines()[: doc.end_lineno]) + "\n"
    examples = len(doc_example_cases(CodeTask("spec", clean, fn.name, "", "")))
    return Spec(clean, fn.name, examples)


def custom_task(spec: Spec, task_id: str) -> CodeTask:
    """A chat problem as a pipeline task. It has no hidden tests and no reference solution."""
    return CodeTask(task_id, spec.text, spec.entry_point, hidden_test="", canonical_solution="")


def _draft_prompt(message: str, current_spec: str | None) -> str:
    if current_spec is None:
        return (f"A user described a programming problem in plain English. Turn it into a "
                f"precise Python function specification for the team.\n\nThe user's request:\n"
                f"{message}\n\n{_SPEC_FORM}")
    return (f"The team is working from this specification:\n```python\n{current_spec.rstrip()}\n"
            f"```\n\nThe user asked for this change:\n{message}\n\nWrite the complete updated "
            f"specification. Keep everything the user did not ask to change.\n\n{_SPEC_FORM}")


def draft_spec(team: Team, message: str, transcript: Transcript, current_spec: str | None = None,
               seed: int = 0) -> Draft:
    """The Research agent writes the spec, with one retry when it is not valid."""
    prompt = _draft_prompt(message, current_spec)
    text, error = "", None
    for attempt in range(2):
        if error:
            prompt += (f"\n\nYour previous reply could not be used ({error}). Reply again with "
                       f"one ```python block in exactly that form.")
        text = spec_text(team["research"].ask(prompt, transcript=transcript, phase="draft",
                                              seed=seed + attempt))
        try:
            spec = validate_spec(text)
        except SpecError as exc:
            error = str(exc)
            continue
        return Draft(spec.text, spec, None)
    return Draft(text, None, error)


def classify(team: Team, message: str, context: str, transcript: Transcript, seed: int = 0) -> str:
    """Is a follow-up a QUESTION about the answer or a CHANGE to the problem? Unclear means
    question: answering is cheap and nothing re-runs."""
    reply = team["coordinator"].ask(
        f"The team solved the problem below. Then the user sent a new message. Decide whether "
        f"the user is asking a QUESTION (about the problem, the answer or how the team got there) "
        f"or asking for a CHANGE to the problem (different behaviour, a new requirement, other "
        f"inputs or outputs).\n\n{context}\n\nThe user's new message:\n{message}\n\n"
        f"Reply with one word: QUESTION or CHANGE.",
        transcript=transcript, phase="classify", seed=seed)
    found = _READING.findall(reply)
    return "change" if found and found[-1] == "CHANGE" else "question"


def answer_question(team: Team, message: str, context: str, history: list[tuple[str, str]],
                    transcript: Transcript, seed: int = 0) -> str:
    """The Coordinator answers a question from the round's evidence."""
    earlier = "".join(f"Q: {q}\nA: {a}\n\n" for q, a in history)
    prompt = (f"The user gave the team a problem and the team answered it. Answer the user's "
              f"question using only the evidence below. Be brief and concrete; quote cases and "
              f"outputs where they help.\n\n{context}\n\n"
              + (f"Earlier questions about this answer:\n{earlier}" if history else "")
              + f"The user's question:\n{message}")
    return team["coordinator"].ask(prompt, transcript=transcript, phase="question", seed=seed)


def round_context(spec: str, answer: dict) -> str:
    """What the Coordinator knows about a finished round, as prompt text."""
    how = answer["source"] + (" (kept because it passes more verified cases)"
                              if answer["repaired"] else "")
    parts = [
        f"Specification:\n```python\n{spec.rstrip()}\n```",
        f"The team's final answer, from {how}:\n```python\n{answer['code'].rstrip()}\n```",
        f"Evidence: {len(answer['candidates'])} candidates showed {answer['distinct_behaviours']} "
        f"different behaviours. The final answer passes {answer['verified_passed']} of "
        f"{answer['verified_total']} verified cases ({answer['spec_cases']} from the "
        f"specification's examples, {answer['ruled_cases']} ruled on by the Coordinator, "
        f"{answer['undisputed_cases']} that no one disputed).",
    ]
    if answer["failures"]:
        parts.append("Verified cases it still fails:\n" + "\n".join(
            f"- {f['call']}: expected {f['expected']}, got {f['got']}" for f in answer["failures"]))
    if answer["rulings"]:
        parts.append("The Coordinator's rulings on disputed cases:\n" + "\n".join(
            f"- {r['call']}: options {', '.join(r['options'])}; chose "
            f"{r['choice'] if r['choice'] is not None else 'UNSURE'}" for r in answer["rulings"]))
    return "\n\n".join(parts)

```python
"""A chat with the team: your messages, spec drafts, team rounds and answers, as one thread.

The thread is its event list. Every event is kept, and the chat is saved to
runs/chats/<id>.json after each one, so the page rebuilds the whole conversation by
replaying it, the same way a live run replays. One action (reading a message or
running a round) happens at a time, in a background thread.
"""

from __future__ import annotations

import json
import os
import threading
import time
import traceback
import uuid
from dataclasses import asdict
from pathlib import Path
from typing import Callable

from .. import chat as talk
from ..agents import Cancelled, Transcript
from ..config import is_safe_name
from ..coordinator import Coordinator
from .events import EventLog

Build = Callable[[], Coordinator]


class ChatError(ValueError):
    """A request the chat cannot carry out; the message says why."""


class ChatBusy(ChatError):
    """The team is still working on this chat's previous action."""


class Chat:
    def __init__(self, chat_id: str, path: Path, config: str, created: float | None = None,
                 events: list[dict] | None = None):
        self.id = chat_id
        self.path = Path(path)
        self.config = config
        self.created = created or time.time()
        self.log = EventLog(events)
        self.busy: str | None = None
        self.thread: threading.Thread | None = None
        self._lock = threading.Lock()
        self._cancel = threading.Event()

    # ------------------------------------------------------------------ files

    @classmethod
    def create(cls, chats_dir: Path, config: str) -> "Chat":
        chat_id = uuid.uuid4().hex[:12]
        chat = cls(chat_id, Path(chats_dir) / f"{chat_id}.json", config)
        chat.save()
        return chat

    @classmethod
    def load(cls, path: Path) -> "Chat":
        data = json.loads(Path(path).read_text(encoding="utf-8"))
        chat = cls(data["id"], path, data["config"], data["created"], data["events"])
        if data.get("busy"):  # the server stopped while the team was working
            chat.log.emit({"type": "done", "action": data["busy"], "status": "interrupted"})
            chat.save()
        return chat

    def save(self) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        data = {"id": self.id, "config": self.config, "created": self.created,
                "busy": self.busy, "events": self.log.events_after(0)}
        tmp = self.path.with_suffix(".tmp")
        tmp.write_text(json.dumps(data), encoding="utf-8")
        os.replace(tmp, self.path)

    # ------------------------------------------------------------------ reading

    @property
    def title(self) -> str:
        first = next((e["text"] for e in self.log.events_after(0) if e["type"] == "message"), "")
        first = " ".join(first.split())
        return first if len(first) <= 60 else first[:59].rstrip() + "…"

    @property
    def updated(self) -> float:
        events = self.log.events_after(0)
        return events[-1]["time"] if events else self.created

    @property
    def finished(self) -> bool:
        """A chat's event stream never ends on its own; the page closes it."""
        return False

    def events_after(self, after: int) -> list[dict]:
        return self.log.events_after(after)

    def wait_events(self, after: int, timeout: float) -> list[dict]:
        return self.log.wait_events(after, timeout)

    def summary(self) -> dict:
        return {"kind": "chat", "id": self.id, "title": self.title, "config": self.config,
                "updated": self.updated, "busy": self.busy}

    def to_dict(self) -> dict:
        return {**self.summary(), "created": self.created, "events": self.log.events_after(0)}

    def _of(self, kind: str) -> list[dict]:
        return [e for e in self.log.events_after(0) if e["type"] == kind]

    def _find(self, kind: str, **match) -> dict | None:
        found = [e for e in self._of(kind) if all(e.get(k) == v for k, v in match.items())]
        return found[-1] if found else None

    def _latest_round(self) -> dict | None:
        """The newest round that has an answer: its spec, its answer and the questions so far."""
        answer = self._find("answer")
        if answer is None:
            return None
        started = self._find("round_started", round=answer["round"])
        questions = [(self._find("message", id=q["message_id"])["text"], q["text"])
                     for q in self._of("question_answer") if q["round"] == answer["round"]]
        return {"round": answer["round"], "spec": started["spec"], "answer": answer["answer"],
                "questions": questions}

    def _current_spec(self) -> str | None:
        """What a change builds on: the newest draft not set aside, or the newest spec that ran."""
        set_aside = {e["spec_id"] for e in self._of("spec_superseded")}
        specs = [(e["seq"], e["text"]) for e in self._of("spec") if e["id"] not in set_aside]
        specs += [(e["seq"], e["spec"]) for e in self._of("round_started")]
        return max(specs)[1] if specs else None

    # ------------------------------------------------------------------ actions

    def _emit(self, event: dict) -> None:
        self.log.emit(event)
        self.save()

    def _start(self, action: str, params: dict, work: Callable[[threading.Event], None],
               first: list[dict] = ()) -> None:
        """Record `first` and the action, then run `work` in the background, one at a time."""
        with self._lock:
            if self.busy:
                raise ChatBusy("The team is still working on this chat. Wait for it, or cancel it.")
            self.busy = action
            self._cancel = cancel = threading.Event()
            for event in first:
                self._emit(event)
            self._emit({"type": "action", "action": action, **params})

        def run() -> None:
            status = "done"
            try:
                work(cancel)
            except Cancelled:
                status = "cancelled"
            except Exception as exc:  # shown in the thread; the server keeps running
                self._emit({"type": "error", "action": action,
                            "message": f"{type(exc).__name__}: {exc}",
                            "trace": traceback.format_exc(limit=5)})
                status = "failed"
            with self._lock:
                self.busy = None
                self._emit({"type": "done", "action": action, "status": status})

        self.thread = threading.Thread(target=run, name=f"chat-{self.id}", daemon=True)
        self.thread.start()

    def send(self, text: str, build: Build) -> str:
        message_id = f"m{len(self._of('message')) + 1}"
        self._start("message", {"message_id": message_id},
                    lambda cancel: self._handle(message_id, None, build, cancel),
                    first=[{"type": "message", "id": message_id, "text": text}])
        return message_id

    def go(self, spec_text: str, spec_id: str, build: Build) -> int:
        if self._find("spec", id=spec_id) is None:
            raise ChatError(f"No spec {spec_id!r} in this chat")
        if self._find("spec_superseded", spec_id=spec_id):
            raise ChatError("That spec was set aside; use the newest one")
        spec = talk.validate_spec(spec_text)
        round_no = len(self._of("round_started")) + 1
        task_id = f"chat/{self.id}/{round_no}"
        self._start("round", {"round": round_no, "spec_id": spec_id},
                    lambda cancel: self._round(round_no, spec, task_id, build, cancel),
                    first=[{"type": "round_started", "round": round_no, "spec_id": spec_id,
                            "spec": spec.text, "task_id": task_id,
                            "entry_point": spec.entry_point}])
        return round_no

    def reinterpret(self, message_id: str, build: Build) -> None:
        classified = self._find("classified", message_id=message_id)
        if classified is None:
            raise ChatError("Only a message the Coordinator read as a question or a change "
                            "can be switched")
        spec = self._find("spec", message_id=message_id)
        if spec and self._find("round_started", spec_id=spec["id"]):
            raise ChatError("That change already ran, so it cannot be read as a question now")
        reading = "change" if classified["reading"] == "question" else "question"
        first = [{"type": "classified", "message_id": message_id, "reading": reading,
                  "automatic": False}]
        if reading == "question" and spec:
            first.insert(0, {"type": "spec_superseded", "spec_id": spec["id"]})
        self._start("reinterpret", {"message_id": message_id, "reading": reading},
                    lambda cancel: self._handle(message_id, reading, build, cancel), first=first)

    def retryable(self) -> dict | None:
        """The last action, when it failed, was cancelled or was cut off by a restart."""
        done = self._find("done")
        if self.busy or done is None or done["status"] == "done":
            return None
        return self._find("action")

    def retry(self, build: Build) -> None:
        action = self.retryable()
        if action is None:
            raise ChatError("There is nothing to retry")
        if action["action"] == "round":
            started = self._find("round_started", round=action["round"])
            self.go(started["spec"], started["spec_id"], build)
            return
        reading = action.get("reading")
        params = {k: action[k] for k in ("message_id", "reading") if k in action}
        self._start(action["action"], params,
                    lambda cancel: self._handle(action["message_id"], reading, build, cancel))

    def cancel(self) -> None:
        self._cancel.set()

    # ------------------------------------------------------------------ work

    def _transcript(self, cancel: threading.Event) -> Transcript:
        return Transcript(f"chat/{self.id}", on_event=self._emit, cancel=cancel)

    def _handle(self, message_id: str, reading: str | None, build: Build,
                cancel: threading.Event) -> None:
        """Read one message: a problem or change gets a spec draft, a question an answer."""
        text = self._find("message", id=message_id)["text"]
        coordinator = build()
        team, seed, tr = coordinator.team, coordinator.seed, self._transcript(cancel)
        latest = self._latest_round()
        if latest is None:
            reading = "change"  # nothing answered yet: every message describes the problem
        elif reading is None:
            reading = talk.classify(team, text, talk.round_context(latest["spec"], latest["answer"]),
                                    tr, seed=seed)
            self._emit({"type": "classified", "message_id": message_id, "reading": reading,
                        "automatic": True})
        if reading == "question":
            reply = talk.answer_question(team, text,
                                         talk.round_context(latest["spec"], latest["answer"]),
                                         latest["questions"], tr, seed=seed)
            self._emit({"type": "question_answer", "message_id": message_id,
                        "round": latest["round"], "text": reply})
            return
        draft = talk.draft_spec(team, text, tr, current_spec=self._current_spec(), seed=seed)
        self._emit({"type": "spec", "id": f"s{len(self._of('spec')) + 1}", "message_id": message_id,
                    "text": draft.text,
                    "entry_point": draft.spec.entry_point if draft.spec else None,
                    "examples": draft.spec.examples if draft.spec else 0, "error": draft.error})

    def _round(self, round_no: int, spec: talk.Spec, task_id: str, build: Build,
               cancel: threading.Event) -> None:
        answer, _ = build().answer(talk.custom_task(spec, task_id), on_event=self._emit,
                                   cancel=cancel)
        self._emit({"type": "answer", "round": round_no, "answer": asdict(answer)})


def load_chats(chats_dir: Path) -> list[Chat]:
    """Every saved chat, newest first. Files that cannot be read are skipped."""
    chats = []
    for path in Path(chats_dir).glob("*.json"):
        if not is_safe_name(path.stem):
            continue
        try:
            chats.append(Chat.load(path))
        except (OSError, ValueError, KeyError, TypeError):
            continue
    return sorted(chats, key=lambda c: c.updated, reverse=True)
```

  - `POST /api/chats/<id>/cancel` → `200 {"cancelling": true}`.
  - `GET /api/status` → `current` can be a chat summary (`kind: "chat"`) while a round runs.

```js
'use strict';

/* The Chat tab: give the team your own problem in plain English and talk about the answer.
   A chat is its event list. The page loads the whole thread once, replays it, then follows
   /api/chats/<id>/events for new events. Uses the helpers and entry builders in app.js. */

const CHAT_PHASES = new Set(['draft', 'classify', 'question']);
const CHAT_BUSY_TEXT = {
  message: 'The team is reading your message…',
  reinterpret: 'The team is reading your message again…',
  round: 'The team is working on the problem. Each step appears below as it happens.',
};
const CHAT_IDLE_TEXT = 'Enter sends, Shift+Enter starts a new line.';

const chat = {
  id: null, es: null, lastSeq: 0, busy: null, currentRound: null, started: false,
  pending: new Map(), // phase -> pending bubble
  specs: new Map(), // spec id -> spec card
  notes: new Map(), // message id -> "read as" note
  rounds: new Map(), // round number -> { box, steps }
  ran: new Set(), // spec ids a round has used
};

const chatPath = (suffix = '') => `/api/chats/${encodeURIComponent(chat.id)}${suffix}`;

function setChatState(text) { $('#chat-state').textContent = text || CHAT_IDLE_TEXT; }

function showChatProblems(items) { showFixes($('#chat-problems'), { problems: items }); }

function problemsOf(err) {
  if (err.status === 409) return [`The team can't start yet: ${err.message}.`];
  return (err.data && err.data.problems) || [err.message];
}

/* ------------------------------------------------------------------ list */

async function loadChatList() {
  let chats;
  try { chats = await api('GET', '/api/chats'); } catch { return; }
  $('#chat-list').replaceChildren(...(chats.length ? chats.map((c) => h('li', {},
    h('button', { type: 'button', dataset: { chat: c.id }, onclick: () => openChat(c.id) },
      h('span', { class: 'name' }, c.title || 'New chat'),
      h('span', { class: 'sub' }, `${c.config}, ${fmtDate(c.updated)}${c.busy ? ', working' : ''}`))))
    : [h('li', { class: 'hint' }, 'No chats yet.')]));
  markChatList();
}

function markChatList() {
  for (const b of $$('#chat-list button')) b.setAttribute('aria-current', b.dataset.chat === chat.id ? 'true' : 'false');
}

async function newChat() {
  showChatProblems([]);
  try {
    const { id } = await api('POST', '/api/chats', { config: $('#chat-config').value });
    await loadChatList();
    await openChat(id);
    return id;
  } catch (err) {
    showChatProblems(problemsOf(err));
    return null;
  }
}

async function showChatTab() {
  if (chat.started) return;
  chat.started = true;
  await loadChatList();
  let last = null;
  try { last = localStorage.getItem('hivemind.chat'); } catch { /* storage blocked */ }
  if (last && $(`#chat-list button[data-chat="${CSS.escape(last)}"]`)) openChat(last);
  else updateComposer();
}

/* ------------------------------------------------------------------ thread */

async function openChat(id) {
  if (chat.es) chat.es.close();
  Object.assign(chat, { id, es: null, lastSeq: 0, busy: null, currentRound: null });
  for (const map of [chat.pending, chat.specs, chat.notes, chat.rounds]) map.clear();
  chat.ran.clear();
  try { localStorage.setItem('hivemind.chat', id); } catch { /* storage blocked */ }
  showChatProblems([]);
  setChatState('');
  markChatList();
  const thread = $('#chat-thread');
  thread.replaceChildren();
  let whole;
  try { whole = await api('GET', chatPath()); } catch (err) {
    thread.replaceChildren(h('ul', { class: 'fixes' }, h('li', {}, err.message)));
    return;
  }
  if (chat.id !== id) return;
  thread.append(h('header', { class: 'chat-head' }, h('h2', {}, whole.title || 'New chat'),
    h('p', { class: 'hint' }, `Config ${whole.config}. Describe a Python function in plain English; once the team has answered, ask about it or ask for a change.`)));
  for (const e of whole.events) handleChatEvent(e, false);
  if (chat.busy) setChatState(CHAT_BUSY_TEXT[chat.busy]);
  window.scrollTo({ top: document.documentElement.scrollHeight });
  chat.es = new EventSource(chatPath(`/events?after=${chat.lastSeq}`));
  chat.es.onmessage = (msg) => handleChatEvent(JSON.parse(msg.data), true);
  updateComposer();
  $('#chat-input').focus();
}

function place(el, parent, live) {
  const target = parent || $('#chat-thread');
  const nearBottom = window.innerHeight + window.scrollY >= document.documentElement.scrollHeight - 160;
  target.append(el);
  if (live && nearBottom) el.scrollIntoView({ block: 'end', behavior: reducedMotion ? 'auto' : 'smooth' });
}

function roundSteps(phase) {
  const round = chat.rounds.get(chat.currentRound);
  return round && !CHAT_PHASES.has(phase) ? round.steps : null;
}

function handleChatEvent(e, live) {
  if (e.seq <= chat.lastSeq) return;
  chat.lastSeq = e.seq;
  const add = (el, parent) => place(el, parent, live);
  switch (e.type) {
    case 'message':
      add(h('div', { class: 'bubble user', dataset: { message: e.id } }, h('p', { class: 'prose' }, e.text)));
      break;
    case 'action':
      chat.busy = e.action;
      for (const b of $$('.retry button', $('#chat-thread'))) b.disabled = true;
      if (live) setChatState(CHAT_BUSY_TEXT[e.action] || 'Working…');
      break;
    case 'classified':
      showReading(e, add);
      break;
    case 'turn_started': {
      const el = turnEntry(e, true);
      chat.pending.set(e.phase, el);
      add(el, roundSteps(e.phase));
      break;
    }
    case 'turn': {
      const pending = chat.pending.get(e.phase);
      chat.pending.delete(e.phase);
      if (CHAT_PHASES.has(e.phase) && !e.error) { // shown by their own spec, note or answer
        if (pending) pending.remove();
        break;
      }
      const el = turnEntry(e);
      if (pending) pending.replaceWith(el); else add(el, roundSteps(e.phase));
      break;
    }
    case 'spec':
      add(specCard(e));
      break;
    case 'spec_superseded':
      setSpecState(e.spec_id, 'superseded');
      break;
    case 'round_started': {
      chat.ran.add(e.spec_id);
      setSpecState(e.spec_id, 'sent', e.spec);
      chat.currentRound = e.round;
      const steps = h('div', { class: 'feed' });
      const box = h('details', { class: 'round', open: true },
        h('summary', {}, `Round ${e.round}: how the team got there`), steps);
      chat.rounds.set(e.round, { box, steps });
      add(box);
      break;
    }
    case 'evidence':
      add(evidenceEntry(e), roundSteps('evidence'));
      break;
    case 'rulings':
      add(e.disputes ? rulingEntry(e.rulings)
        : systemEntry('Arbitration', 'No disputed cases: every program that ran agreed with the verified expectations, so there was nothing to rule on.'),
      roundSteps('rulings'));
      break;
    case 'answer': {
      const round = chat.rounds.get(e.round);
      if (round) round.box.open = false;
      chat.currentRound = null;
      add(answerCard(e.round, e.answer));
      break;
    }
    case 'question_answer':
      add(h('article', { class: 'entry' }, entryHead(who('coordinator'), 'Answer', `about round ${e.round}`),
        renderReply(e.text)));
      break;
    case 'error':
      add(systemEntry('Something went wrong', e.message, true));
      break;
    case 'done': {
      chat.busy = null;
      chat.currentRound = null;
      for (const el of chat.pending.values()) el.remove();
      chat.pending.clear();
      if (e.status !== 'done') add(retryNote(e));
      if (live) { setChatState(''); loadChatList(); }
      break;
    }
    default:
      break;
  }
  updateComposer();
}

  const old = chat.notes.get(e.message_id);
  chat.notes.set(e.message_id, note);
  if (old) old.replaceWith(note); else add(note);
}

function verifiedLine(a) {
  if (!a.verified_total) {
    return 'No verified cases: the spec had no usable examples and the Testing agent wrote no usable tests, so nothing checked this answer.';
  }
  const parts = [];
  if (a.spec_cases) parts.push(`${a.spec_cases} from your examples`);
  if (a.ruled_cases) parts.push(`${a.ruled_cases} ruled on by the Coordinator`);
  if (a.undisputed_cases) parts.push(`${a.undisputed_cases} no one disputed`);
  let head;
  if (a.verified_passed !== a.verified_total) head = `Passes ${a.verified_passed} of ${plural(a.verified_total, 'verified case')}`;
  else head = a.verified_total === 1 ? 'Passes its 1 verified case' : `Passes all ${a.verified_total} verified cases`;
  return `${head}: ${parts.join(', ')}.`;
}

function answerCard(round, a) {
  const flagged = a.unsafe.filter(Boolean).length;
  return h('article', { class: `entry answer-card${a.working ? '' : ' failed'}` },
    entryHead(who('coordinator', 'Team answer'), `Round ${round}`,
      a.repaired ? `${a.source}, kept because it passes more verified cases` : a.source),
    a.working ? null : h('p', { class: 'note' }, 'No candidate produced working code. This is the best attempt, and the failures below show why. Send a message to change the problem.'),
    h('p', { class: 'verified' }, verifiedLine(a)),
    h('pre', { class: 'code' }, a.code || '(no code)'),
    a.failures.length ? h('div', { class: 'failures' }, h('h4', {}, 'Verified cases it still fails'),
      h('ul', {}, a.failures.map((f) => h('li', {}, h('code', {}, f.call), ` should give ${f.expected}, gives ${f.got}`)))) : null,
    flagged ? h('p', { class: 'note' }, `${plural(flagged, 'candidate')} flagged by the security scan.`) : null);
}

function retryNote(e) {
  const text = { failed: 'This step stopped with an error.', cancelled: 'Cancelled.',
    interrupted: 'The server stopped before the team finished.' }[e.status] || e.status;
  return h('div', { class: 'retry actions' }, h('span', { class: 'hint' }, text),
    h('button', { type: 'button', onclick: retryChat }, 'Retry'));
}

function updateComposer() {
  const busy = !!chat.busy;
  $('#chat-send').disabled = busy;
  $('#chat-cancel').hidden = !busy;
  for (const b of $$('.reading button, .spec-card .go', $('#chat-thread'))) b.disabled = busy || b.dataset.locked === 'true';
}

/* ------------------------------------------------------------------ actions */

async function sendChat(ev) {
  ev.preventDefault();
  const input = $('#chat-input');
  const text = input.value.trim();
  if (!text || chat.busy) return;
  if (!chat.id && !(await newChat())) return;
  showChatProblems([]);
  try {
    await api('POST', chatPath('/messages'), { text });
    input.value = '';
  } catch (err) {
    showChatProblems(problemsOf(err));
  }
}

async function startRound(specId, box, problems) {
  problems.hidden = true;
  try {
    await api('POST', chatPath('/go'), { spec: box.value, spec_id: specId });
  } catch (err) {
    problems.replaceChildren(...problemsOf(err).map((t) => h('li', {}, t)));
    problems.hidden = false;
    if (err.data && err.data.line) focusLine(box, err.data.line);
  }
}

function focusLine(box, line) {
  const lines = box.value.split('\n');
  const start = lines.slice(0, line - 1).reduce((n, l) => n + l.length + 1, 0);
  box.focus();
  box.setSelectionRange(start, start + (lines[line - 1] || '').length);
}

async function reinterpret(messageId) {
  showChatProblems([]);
  try { await api('POST', chatPath('/reinterpret'), { message_id: messageId }); } catch (err) { showChatProblems(problemsOf(err)); }
}

async function retryChat(ev) {
  ev.currentTarget.disabled = true;
  showChatProblems([]);
  try { await api('POST', chatPath('/retry')); } catch (err) { showChatProblems(problemsOf(err)); }
}

$('#chat-form').addEventListener('submit', sendChat);
$('#chat-input').addEventListener('keydown', (ev) => {
  if (ev.key === 'Enter' && !ev.shiftKey && !ev.isComposing) {
    ev.preventDefault();
    $('#chat-form').requestSubmit();
  }
});
$('#chat-new').addEventListener('click', newChat);
$('#chat-cancel').addEventListener('click', async () => {
  setChatState('Cancelling once the current model call finishes.');
  try { await api('POST', chatPath('/cancel')); } catch (err) { setChatState(err.message); }
});
```
